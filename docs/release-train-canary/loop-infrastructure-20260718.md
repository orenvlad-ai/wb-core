# LOOP Release Train infrastructure canary

Этот файл — временный repository-tracked documentation-only маркер первого bounded LOOP-canary новой инфраструктуры Release Train.

- Runtime behavior, production data, конфигурация и бизнес-логика не изменяются.
- `scope:live-runtime` используется только для проверки LOOP handshake, canonical deploy и UI gate.
- UI acceptance допускается только после успешного read-only production UI Flow.
