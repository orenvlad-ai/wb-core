# Политика поисковых кластеров WB

## Область применения

Профильная политика для задач аудита и управления поисковыми фразами и кластерами CPM-кампаний узкоспецифичных товаров. Читать только при работе с этим механизмом; для остальных задач не требуется. Не является общей инструкцией AGENTS.md или политикой рекламных ставок.

Источник: согласованный свод WBC 0072K1 от 10.09.2026. Версия 1. Правила ниже сохранены по итоговому документу куратора.

## Согласованные правила

Политика исключения поисковых фраз и кластеров для узкоспецифичных товаров

1. **Главный критерий — соответствие конкретному товару и его совместимости.** Перед чисткой определи точную модель, для которой предназначен товар. Для стекла на iPhone 16 Pro Max запросы на iPhone 16 или iPhone 16 Pro нецелевые: это другие устройства.

2. **Явно другую модель исключаем.** Не предполагаем, что покупатель не дописал название или подразумевал нашу модель. «iPhone 16» не означает «iPhone 16 Pro Max».

3. **Широкие запросы без нужной модели исключаем.** Для такого товара «стекло», «защитные стекла», «защитное стекло для iPhone» слишком общие. Принадлежности к одной категории недостаточно: запрос должен выражать потребность именно в нашем совместимом товаре.

4. **Варианты написания сохраняем, если смысл соответствует нужной модели.** Русские и английские названия, транслит, словоформы, слитное написание, понятные опечатки и ошибки раскладки сами по себе не являются причиной исключения. Например, «айфон 16 про макс» и «iPhone 16 ProMax» подходят.

5. **Все свойства нашего товара в запросе необязательны.** Для матового стекла подходит «стекло iPhone 16 Pro Max»: покупатель может выбрать матовое, увидев предложение. Слова «матовое» или «с автоустановкой» необязательны. При этом явно запрошенный другой товар или несовместимое свойство — основание для исключения, например антишпионное стекло для кампании обычного матового.

6. **Однозначного названия фразы или кластера достаточно для решения.** Если в названии явно другая модель или слишком общий запрос, исключаем. Не оправдываем сохранение предположением, что внутри кластера могут скрываться подходящие запросы.

7. **Неоднозначность проверяем через обычный поиск Wildberries.** Вводим запрос и оцениваем выдачу: представлены ли товары конкурентов, совместимые именно с нашей моделью. Для матового стекла на 16 Pro Max конкурентами здесь считаются любые защитные стёкла на 16 Pro Max, необязательно матовые. Отдельный случайный подходящий товар не отменяет явно другую модель в запросе. Если смысл всё ещё неясен — оставляем на отдельный разбор.

8. **Релевантность и эффективность оцениваем отдельно.** Целевой запрос не исключаем только из-за отсутствия заказов на коротком отрезке. Случайный клик или заказ по явно нецелевому запросу не отменяет правила совместимости.

9. **Не переносим строгость модели на любые категории механически.** Для красной или укороченной юбки общий запрос «юбка» может подходить: покупатель ещё выбирает вариант. Для стекла под конкретное устройство модель определяет совместимость, поэтому она обязательна.

Порядок работы: определить товар и совместимость → проверить смысл запроса → исключить очевидно нецелевое → разобрать неоднозначное → зафиксировать причину и проверить, что исключение применилось. Уже исключённые кластеры повторно не отключать.

## Применение в задачах

При назначении профильной задачи передавать прямую ссылку на этот документ. Политика определяет критерии, но сама не разрешает записи в WB: границы конкретной задачи задаёт пользователь.

В режиме аудита подготовить по каждой кампании идентификатор, SKU и совместимость, текущий статус кластера, предлагаемое действие (исключить, вернуть, оставить или отдельный разбор), номер правила и обоснование. Для неоднозначных случаев фиксировать запрос, регион и результат обычного поиска WB. Доступную статистику сопровождать периодом; отсутствующие данные не считать нулём. Отдельно перечислить непроверенные кампании и причины.

После одобрения конкретного списка изменений проверить актуальное состояние цели, применить только согласованные действия и подтвердить результат чтением. Не повторять уже применённое исключение. Не менять ставки, бюджеты, статусы кампаний или расписание контроля без соответствующего задания.
