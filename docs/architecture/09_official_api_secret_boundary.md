# Секреты и внешние API

- Токены, пароли, ключи SSH, cookies и полные production-выгрузки не хранятся в Git.
- Локальные секреты остаются в системном или пользовательском хранилище;
  production-секреты — на сервере или в GitHub Environment.
- Клиентский интерфейс не получает секрет, если запрос может выполнить сервер.
- Логи и receipts содержат безопасные идентификаторы и хеши, а не секретные значения.
- Проверка PR выполняется без production-ключей. Ключи доступны только доверенному
  выпуску или явно запущенной production-операции.
- При ошибке авторизации не подставляй другой аккаунт, сервер или старый токен по догадке.

Каждый модуль дополнительно ограничивает нужные ему методы API, область аккаунта,
частоту запросов и допустимые записи.

## Браузерная проверка WebCore

Для локальных браузерных проверок используй отдельный аккаунт Codex и обычную
форму входа `https://api.selleros.pro/login`. Пользователь разрешил сохранять
учётные данные этого аккаунта локально и выполнять вход самостоятельно.

На Mac владельца запись находится в связке ключей macOS: generic password,
service `wbc.codex.browser.api.selleros.pro`, account `codex-browser`.
Значение — JSON с `origin`, `username`, `password`; account записи хранилища
не является логином сайта. Локальная инструкция без секретов:
`~/.local/share/wbc-browser-access/README.md`.

Читай запись только в память локального процесса и передавай значения полям
входа только после проверки точного origin `https://api.selleros.pro`.
Не выводи значения в переписку, команды, логи, снимки заполненной формы,
артефакты, Git или CI. Не извлекай cookies пользователя и не подменяй сессию
через сервер. На другом компьютере эта локальная запись недоступна.

После входа проверь целевую страницу и ожидаемый результат реализации.
Доступность `/login` сама по себе не считается браузерной проверкой.
Использование аккаунта не расширяет разрешённые задачей изменения рабочих
данных. Если запись отсутствует, macOS требует разрешение или вход отклонён,
сообщи конкретный блокер; не перебирай другие аккаунты и старые секреты.
