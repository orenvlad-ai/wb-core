# Целевая архитектура

`wb-core` — модульное приложение с одним репозиторием и общей production-средой.
Разделение на модули нужно для ясных владельцев данных и независимых изменений,
а не для создания множества сервисов без практической пользы.

## Слои

1. Адаптеры получают данные из официальных API, файлов и разрешённых web-источников.
2. Предметная логика нормализует данные, сохраняет происхождение и рассчитывает результат.
3. Server-owned хранилища держат текущее и историческое состояние.
4. Web Vitrina и выгрузки показывают уже подготовленную модель, не создавая
   параллельную бизнес-логику в интерфейсе.

## Общие свойства

- один показатель имеет один канонический источник;
- `missing`, `partial`, `stale` и точный ноль различаются;
- время события, рабочая дата и время получения не смешиваются;
- публикация крупных наборов выполняется candidate-first и pointer-last;
- повторяемые записи идемпотентны или защищены CAS/operation identity;
- секреты и изменяемые production-данные не хранятся в Git;
- область может развиваться самостоятельно, пока сохраняет общие контракты
  данных, публикации и восстановления.

Подробности конкретной области находятся в её документе из
[`docs/modules/`](../modules/00_INDEX__MODULES.md).
