# WBC0069K16: проверочный готовый снимок витрины, этап 1

Это ограниченный opt-in/manual-build пилот. Обычный page composition и window V3 остаются путём по умолчанию. Здесь нет таймера, очереди, нового расчётчика или переноса данных production.

## Ручная сборка и публикация

Источник — **полный завершённый** `web_vitrina_page_composition`, уже рассчитанный существующими `SheetVitrinaV1WebVitrinaBlock → view model → gravity adapter → page composition` на явно выбранных 14 или 31 датах. Предпочтителен существующий полный `indexed_cells_v2` (версия ответа 2); полный legacy (версия 1) при импорте переводится в тот же формат. Вызывающая сторона сначала сохраняет trusted JSON результата в локальный файл. Shell, Loading, error, неполные счётчики строк, каталог групп/дат/ячеек отклоняются до записи. Пилотный импорт:

```sh
python3 apps/web_vitrina_snapshot_pilot_smoke.py --import-artifact /path/to/finished_full_projection.json --store /path/to/explicit_pilot.sqlite3 --date-from 2026-04-07 --date-to 2026-04-20
```

Каталог и все 16 полей ячеек берутся из готового adapter result без повторения формул; существующий `indexed_cells_v2` сохраняется и передаётся без распаковки всего периода. Лимит суммарного JSON артефакта остаётся 128 MiB. Запись immutable generation и переключение указателя последнего готового поколения происходят в одной транзакции отдельной SQLite. Если валидация или транзакция не завершилась, прежний указатель остаётся. Хранилище включается в HTTP-сервер **только явным** `snapshot_pilot_store=...`; нет автосоздания на GET. Пилотный GET открывает только это хранилище `mode=ro`/`query_only` и не вызывает business evaluator.

## Проверочный UI

`?history_mode=explicit&date_from=...&date_to=...&snapshot_pilot=1` загружает только готовые TOTAL/GROUP rows. Кнопка «Показать SKU этого снимка» отдельно получает SKU rows по тому же immutable `generation_id`; возможная новая публикация не смешивается с уже открытым поколением. В таблице показывается время сохранения именно выбранной generation, а не время повторного открытия страницы. Пока SKU не получены, поиск и сортировка по всему каталогу отключены: вывод по summary не объявляется глобальным. Проверки статуса projection в этом режиме не запускают legacy full/V3 reload. Кнопка обновления источников скрыта. Доступ к обоим GET проходит через обычную проверку Web Vitrina HTTP auth и scope.

Локальный сервер с синтетическим fixture и сравнимым обычным путём:

```sh
python3 apps/web_vitrina_snapshot_pilot_smoke.py --serve
```

Команда печатает URL 14 и 31 дней с `snapshot_pilot=1`, те же URL без него, путь временного SQLite и полные fixture JSON. Числа времени этого fixture не описывают production. `python3 apps/web_vitrina_snapshot_pilot_smoke.py` проверяет точный row/cell/column parity 14/31, HTTP, браузерное раскрытие и обычный путь, сохранение last-good при сбое, отказ от усечённых таблиц и отсутствие evaluator на пилотном GET. Отдельный **синтетический структурный** тест около 8000 строк × 31 дата проверяет размер компактного артефакта относительно 128 MiB; это не production benchmark.

Это только функциональный кандидат этапа 1. Реальный finished artifact, его происхождение, ресурсные показатели на реальных входах и безопасное включение вне локального fixture ещё не подтверждены. После проверки 14/31 работа останавливается до отдельного решения следующего этапа.
