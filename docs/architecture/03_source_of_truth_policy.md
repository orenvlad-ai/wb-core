# Источники истины

При расхождении используй источник, который непосредственно владеет фактом:

1. `origin/main` — текущий код и версионируемые контракты.
2. Предметный документ модуля — смысл показателя и допустимые преобразования.
3. GitHub — состояние PR, проверок, слияния и выпуска.
4. Канонический production-сервер и его хранилища — фактическое runtime/data-состояние.
5. Официальный внешний API или исходный файл — внешний первичный факт.

Чат, отчёт, лог, migration-файл и старый receipt могут быть доказательством, но
не заменяют свежую проверку изменяемого состояния.

## Обязательные различия

- отсутствие данных не превращается в ноль;
- рассчитанное значение не выдаётся за исходное;
- текущий снимок не переносится задним числом без доказательства;
- локальная копия не объявляется production-состоянием;
- секреты читаются только из разрешённого локального или server-owned хранилища.

Если источники расходятся, останови затронутое действие, назови расхождение и
собери минимальное доказательство, необходимое для решения.
