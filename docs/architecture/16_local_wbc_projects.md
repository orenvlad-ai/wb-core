# Локальные проекты WBC

## Назначение и единый источник

WBC_dev — разработка (сохраняется физическая папка `/Users/ovlmacbook/Documents/ChatGPT/WBC_new`).
WBC_ops — постоянная операционная работа, папка `/Users/ovlmacbook/Documents/ChatGPT/WBC_ops`.
WBC_cloud — отдельная облачная среда; локальные файлы Mac не делают её доступной при выключенном Mac.

Оба локальных проекта читают `/Users/Shared/WBC/rules/AGENTS.md` и документы из той же папки.
В проектах нет собственных копий общих правил. Общую копию обновляют из main после PR.
Правила перечитываются перед новым поручением, в том числе в существующем чате.

## Доступы и ресурсы

Локальные проекты используют один профиль текущего пользователя Codex, его инструменты,
подключения, SSH и защищённое хранилище WebCore. Секреты и cookies не копируются.
Набор инструментов конкретного чата проверяется при работе: наличие файла с правилами
не предоставляет права в сервисе и не гарантирует доступность каждого подключения.
Вход WebCore — по общему навыку `~/.codex/skills/wbc-browser-login/SKILL.md`.

В WBC_ops каталог `shared/` содержит ссылки: `rules` на общие правила,
`development` на WBC_new, `repository` на `/Users/ovlmacbook/Projects/wb-core`.
Перед работой с кодом выбирают актуальную отдельную ветку по общим правилам;
наличие ссылки не означает, что рабочая копия актуальна или свободна для записи.

## Операционные документы

`factory/inbox/` — полученные оригиналы; `factory/reconciliations/` — сверки;
`factory/payments/` — документы оплат; `factory/reports/` — результаты;
`registry/` — ссылки на постоянные чаты и происхождение документов;
`output/` — прочие результаты; `tmp/` — временные файлы.
Оригиналы сохраняются без перезаписи. Финансовые документы остаются вне Git.
По завершении этапа сохраняют результат с датой и ссылкой на источник;
неподтверждённые данные не превращают в нулевые суммы или проведённые операции.

## Нумерация

Разработка использует прежний счётчик. Ops использует команду
`python3 /Users/Shared/WBC/rules/docs/local_tools/wbc_chat_number.py THREAD_ID --series ops --title "краткая тема"`.
Формат `WBC 0001O Сверка с фабрикой`, затем `WBC 0002O ...`.
Счётчик Ops — `/Users/Shared/WBC/ops-chat-numbers.sqlite3`, та же транзакционная схема.
При первичной настройке его создают один раз с нулём; при потере не создают заново.
Повторное обращение с тем же ID возвращает тот же номер. Помощники номера не получают.
При переносе постоянного чата старое название записывают в `registry/chats.json`.
Закрепление и проверка полного названия выполняются так же, как в разработке.

## Подключение в приложении

Добавить WBC_ops как локальный проект с указанной папкой и переместить туда существующий
чат сверки. Перемещение записи в боковой панели само по себе не доказывает смену
рабочей папки старого чата: проверить его cwd и доступ к общим ресурсам.
Если старый чат сохраняет WBC_new, использовать абсолютные пути WBC_ops;
общие глобальные инструкции также распознают зарегистрированный ID операционного чата.
