# Локальные проекты WBC

## Два проекта, одна папка

WBC_new — разработка (целевое отображаемое название WBC_dev).
WBC_ops — постоянные операционные чаты.
Оба локальных проекта подключены к `/Users/ovlmacbook/Documents/ChatGPT/WBC_new`.
Разделение проектов организует историю чатов; файлы и рабочая среда общие.
WBC_cloud сохраняет свою облачную среду и нумерацию C.

## Общие правила и доступы

Единый источник — `/Users/Shared/WBC/rules/AGENTS.md` и документы в той же папке.
Правила обновляют через PR в main, затем обновляют общую копию на Mac.
В начале нового поручения, включая продолжение постоянного чата, правила перечитывают.
В общей рабочей папке остаётся одна инструкция, направляющая к этому источнику.

Используется один профиль текущего пользователя: инструменты, подключения, SSH,
защищённое хранилище WebCore и настройки разрешений. Секреты и cookies не копируются.
Наличие общих файлов не доказывает доступность подключения в конкретном чате:
при работе проверяют фактические разрешения и источники.
Вход WebCore — по общему навыку `~/.codex/skills/wbc-browser-login/SKILL.md`.
Если приложение требует подтверждения доступа при переносе чата, пользователь
переносит его через боковую панель. После переноса проверяют проект и рабочую папку.

## Единый реестр чатов

Для WBC_new и WBC_ops используется один существующий реестр
`/Users/Shared/WBC/chat-numbers.sqlite3` и одна команда:
`python3 /Users/Shared/WBC/rules/docs/local_tools/wbc_chat_number.py THREAD_ID --title "краткая тема"`.

Формат `WBC 0204 Краткая тема`, без буквенных индексов и разделителей.
Новый чат в любом из этих проектов получает следующий общий номер.
Повторный ID возвращает прежний номер; перенос между проектами не меняет номер.
Помощники номера не получают. При потере реестра его не создают заново.
Ранее выделенная серия Ops отменена; для уже зарегистрированных чатов восстанавливают
номер из общего реестра, а не выделяют новый. Облачный счётчик не меняется.

## Операционные документы

Документы хранятся в `WBC_new/operations/`:
`factory/inbox/` — оригиналы, `factory/reconciliations/` — сверки,
`factory/payments/` — документы оплат, `factory/reports/` — результаты;
`output/` — прочие результаты, `tmp/` — временные файлы.
Каталог исключается из Git; первичные финансовые документы не коммитятся.
Оригиналы не перезаписывают. Результат сохраняют с датой и ссылкой на источник;
неподтверждённые данные не превращают в нулевые суммы или проведённые операции.
Папка operations не содержит собственных AGENTS.md, секретов или счётчика чатов.

## Одновременная работа

Общая папка не разрешает параллельную запись в одни файлы. Разработку ведут
в отдельных ветках и рабочих копиях по общим правилам; операционные документы
разделяют по задачам. Записями бизнес-данных управляет один ответственный.
