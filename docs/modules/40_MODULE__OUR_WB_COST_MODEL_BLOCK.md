# Module 40 — Наша себестоимость WB

## Каноническое значение

`our_wb_unit_cost_rub` — версия себестоимости конкретного `nmId` на рабочую
дату. Значение берётся из подтверждённой складской истории и не заменяется
средним по группе, чужим SKU, текущим значением задним числом или нулём.

До даты начала подтверждённой ежедневной истории допустима только явно
описанная ретроспективная проекция того же `nmId`. После неё используется
канонический daily WB WAC.

## Потребители

- финансовые отчёты и прибыльность;
- Proxy 3/4;
- товарный капитал;
- Partner report и другие явно подключённые read-side.

Потребитель получает значение вместе с датой, версией, качеством и источником.
Отсутствие или конфликт остаются `missing`/`partial`, а не превращаются в ноль.

## Изменение истории

Историческое исправление ограничивается точным SKU, датой и версией. Перед
записью проверяются кандидат, затрагиваемые потребители, состояние до изменения
и восстановление; после записи — количества, суммы и неизменность остальных
данных.
