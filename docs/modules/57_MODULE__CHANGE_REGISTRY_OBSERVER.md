# Module 57 — Реестр внешних изменений

## Назначение

Модуль без записи наблюдает официальные Prices и Ads и показывает изменения,
произошедшие вне `wb-core`.

Первое полное наблюдение создаёт baseline без факта изменения. Далее факт
возникает только между двумя точными сопоставимыми значениями одной identity.
`missing`, `partial`, `inapplicable` и неоднозначная связь не продвигают
доказанный baseline.

## Хранение и чтение

- наблюдения и факты append-only;
- повтор одного снимка идемпотентен;
- неоднозначная campaign → nmId связь создаёт incident без выдуманного target;
- комментарии не меняют внешний факт;
- API и UI доступны только авторизованным ролям.

## Выполнение

Периодический и ручной запуск используют один seller-scope lease. Запоздалый
или ошибочный запуск виден в health, но не запускает параллельный дубль. Модуль
не выполняет WB POST/PATCH и не является общим монитором задач Codex.
