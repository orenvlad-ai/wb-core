# Module 59 — Здоровье Web Витрины

## Назначение

Модуль показывает, насколько свежи и пригодны данные Web Витрины. Зелёный
статус означает подтверждённое состояние данных, а не только успешный запуск
таймера или процесса.

## Основные правила

- `missing`, `partial`, `stale` и `zero` — разные состояния; отсутствие данных
  нельзя выдавать за ноль.
- Для закрытой даты источником истины служит подтверждённый закрытый снимок.
- Обычное обновление не должно незаметно переписывать закрытую историю.
- Ошибка одного источника показывается явно и не скрывается общим успешным
  статусом.
- Состояние здоровья читается без записи; исправление данных — отдельная
  ограниченная операция с собственным preview и readback.

## Код и проверка

- расчёт: `packages/application/sheet_vitrina_v1_health.py`;
- фоновая проверка: `apps/sheet_vitrina_v1_health_tick.py`;
- HTTP и интерфейс: `packages/adapters/registry_upload_http_entrypoint.py`;
- короткие проверки: `apps/sheet_vitrina_v1_health_smoke.py` и
  `apps/sheet_vitrina_v1_health_browser_smoke.py`.

При изменении проверяются только затронутые показатели и пользовательский путь.
Полный исторический пересчёт сам по себе в проверку модуля не входит.
