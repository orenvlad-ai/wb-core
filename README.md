# wb-core

`wb-core` — основной репозиторий внутренних сервисов Web Vitrina: сбор данных
Wildberries и других источников, расчёты, складской учёт, финансы, поставки,
реклама, отзывы и операторский интерфейс.

## Основные части

- `apps/` — запускаемые сервисы, команды и проверочные сценарии;
- `packages/` — предметная логика, адаптеры и контракты;
- `artifacts/` и `registry/` — версионируемые конфигурации и публичные входные
  данные без секретов;
- `gas/` — сохраняемые Google Apps Script-компоненты;
- `docs/modules/` — действующие предметные контракты;
- `docs/architecture/` — короткие общие границы системы;
- `ci/` и `.github/workflows/` — проверки и выпуск.

## Работа с репозиторием

Начинай с [`AGENTS.md`](AGENTS.md). Он содержит общий рабочий минимум и ссылки
на документы, нужные только в конкретной ситуации.

Источником текущего кода является `main`. Источником production-состояния
являются фактический сервер и его хранилища. История изменений остаётся в Git и
не дублируется отдельными журналами в рабочей документации.

Карта предметных областей: [`docs/modules/00_INDEX__MODULES.md`](docs/modules/00_INDEX__MODULES.md).
